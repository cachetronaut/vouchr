# vouchr

TypeScript implementation of Vouchr.

For product-level context, shared contracts, and cross-language repository information, see the public repository: https://github.com/cachetronaut/vouchr.

## Install

```sh
npm install vouchr
```

## Development

Run from `ts/`:

```sh
pnpm install
pnpm verify
pnpm build
```
